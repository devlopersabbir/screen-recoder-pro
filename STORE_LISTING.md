## 🔐 Permissions Justification (For Store Reviewers)

| Permission / API | Usage in Extension | Reviewer Justification |
| :--- | :--- | :--- |
| `navigator.mediaDevices.getDisplayMedia()` | Core screen recording | Required to trigger the browser's native screen picker dialog so the user can select a display, window, or tab to capture. Capture is initiated strictly on user interaction. Streams are encoded in-memory and never sent to any external server. |
| `action` / `browser_action` (Popup) | Extension UI | Required to provide the user interface where the user can initiate recordings, view live status, stop capture, and trigger local file download. |
| `activeTab` / Content Scripts | **None** | This extension does not inject content scripts and does not inspect DOM contents of user tabs. |
| `storage` | **None** | Recordings are kept in temporary memory during capture and handed off to the native browser download manager. |

## ❓ Frequently Asked Questions (FAQ) for Store Listings

**Q: Is Screen Recorder Pro completely free?**  
A: Yes, Screen Recorder Pro is 100% free and open-source under the MIT license. There are no hidden fees, paywalls, or in-app purchases.

**Q: Are there watermarks on my videos?**  
A: No. We never add watermarks, branding, or overlays to your recorded videos.

**Q: Where are my recordings saved?**  
A: Recordings are saved directly to your browser's default Downloads folder as standard `.webm` video files.

**Q: Does Screen Recorder Pro upload my video to any cloud server?**  
A: Absolutely not. All video capture and encoding happens locally inside your browser memory. Nothing is ever sent to any remote server.

**Q: What video format is used?**  
A: Recordings are packaged in the open WebM container using high-efficiency VP9 or VP8 video codecs, playable in all modern media players (VLC, QuickTime with WebM, browsers) and video editing software.
